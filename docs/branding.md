# Логотип AsiaMotors

Утверждённый исходник: `asiamotors-logo.png`, пропорции 3:2. Сайт использует
оптимизированный WebP, сохраняя весь рисунок и прозрачность. Иконки браузера,
Apple и двух PWA содержат тот же логотип без обрезки, на тёмном квадратном фоне.
Маленькие favicon 16–48 px используют целый знак над надписью: мелкий текст
исключён из этой версии, чтобы знак оставался различимым на вкладке браузера.
Старый публичный PNG-адрес сохранён с новым изображением для внешних ссылок.

Повторная подготовка ресурсов из исходника:

```sh
node scripts/generate-brand-assets.mjs /absolute/path/to/asiamotors-logo.png
```

Скрипт обновляет изображения и `shared/constants/branding.ts`. Компоненты,
метаданные страниц и манифесты используют эти общие адреса. Версия в имени WebP
и параметре URL иконок зависит
от исходника и скрипта обработки: после выпуска браузер загружает новые файлы,
даже если предыдущие изображения закешированы надолго.

При замене исходника нужно пересмотреть область знака для favicon в скрипте.
При смене пропорций нужно также пересмотреть размеры в `Logo`,
`Header`, `AdminShell` и на странице входа. Обе PWA сохраняют свои ID, названия,
области действия и стартовые страницы. Перерегистрация service worker не нужна.
