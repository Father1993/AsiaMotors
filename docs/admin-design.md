# AsiaMotors: рабочее пространство каталога

Менеджер добавляет реальные автомобили, фотографии и комплектации с компьютера или телефона.
Основной объект экрана — автомобиль: обложка, марка, модель, цена и состояние публикации.
Территория: наличие, поставка под заказ, пробег, комплектация, фотогалерея, публикация.
Палитра: белый кузов, графит приборной панели, серый металл, красный акцент марки, зелёное подтверждение.

Оболочка: светлый фон, белые рабочие области, тонкие разделители. Один красный акцент.
Локальные Inter для полей и Montserrat для заголовка; размер ввода 16px, заголовок 28px/24px.
Сетка 4/8px, панели 24px/16px, контролы 44–48px, скругления 8px/12px.
Обычные поля HTML, Headless UI для диалогов. Полные подписи, видимый фокус, ошибки у полей.

Список: фотография и название ведут, цена с tabular-nums, два отдельных признака:
состояние публикации и «В наличии / Под заказ». На телефоне строки становятся карточками.
Редактор: одна страница с разделами, компактное превью и доступные действия сохранения.
Фото: первое — обложка, порядок меняется явными кнопками без обязательных жестов.

Кнопки: .admin-button, .admin-button-primary, .admin-button-danger.
Поля: Field + .admin-field; панели: .admin-panel. Палитра — CSS-переменные .admin-shell.
Загрузка, пустой результат, ошибка, успех, отключённое действие проверяются отдельно.

Заявки: менеджер видит контакт клиента, предмет обращения и два независимых состояния —
обработка и письмо. Основной акцент — имя и телефон; служебные подробности вынесены в карточку.
Палитра и типографика каталога сохраняются. Семантические цвета обозначают успех, ожидание и ошибку.
Список становится карточками на телефоне; письмо никогда не означает «заявка обработана».
В карточке — полный текст обращения, изменение рабочего статуса и сведения о состоянии отправки.

Блог: редактор сверяет существующие статьи и адреса публикаций. На первом плане — заголовок
и обложка; дата, автор и теги помогают найти материал. Чтение без кнопок изменения контента.
Публичные адреса, материалы и оформление сайта сохраняются. Общие шаг 4/8px, панели 16/24px,
контролы 44–48px и красный акцент остаются основой обоих разделов.
