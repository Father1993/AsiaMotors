# Установка приложений AsiaMotors

Доступны два приложения одного сайта:

- Для клиента: откройте сайт, установите «AsiaMotors — автомобили».
- Для менеджера: откройте админку, установите «AsiaMotors — управление».
  Приложение открывается на обзоре работы; при необходимости потребуется вход.

В поддерживаемых Chromium-браузерах появится рабочая кнопка установки после
системного события браузера. На iPhone/iPad используйте «Поделиться» → «На экран
Домой». Для Safari на Mac интерфейс подсказывает добавление в Dock. В Android-
браузере без системного предложения доступна инструкция через меню; некоторые
браузеры создают только ярлык. Возможности установки зависят от браузера и ОС.
Это web-приложения, публикация в App Store или Google Play не требуется.

Предложение можно отложить на семь дней. В установленном приложении оно скрыто.
Приложение менеджера имеет отдельное имя, иконку и стартовый адрес. Оба manifest
имеют scope `/`, чтобы авторизация по `/auth/signin` оставалась в окне приложения;
доступ к админке всё равно проверяется сервером.

## Обновления и отсутствие сети

Обновление предлагается отдельной кнопкой. Сначала сохраните работу или завершите
заполненную форму. Другие вкладки автоматически не перезагружаются.

Service worker сохраняет только две нейтральные offline-страницы. Он не сохраняет
административные страницы, заявки, API, авторизацию, RSC-ответы, каталог или цены.
Без сети изменения не отправляются: не закрывайте заполненную форму, восстановите
подключение и сохраните данные. Offline-страница не подтверждает авторизацию.

Для каждого выпуска worker получает версию сборки Next.js. На сервере не нужно
настраивать отдельный сервис push-уведомлений или внешний PWA-сервис.

## Проверка

`tests/browser/pwa.spec.ts` проверяет manifest, размеры PNG, предложения установки,
iPad/Android-инструкции, защиту заполненных форм и реальный CacheStorage.
Программные проверки браузера не заменяют приёмку установки на физическом iPhone,
Android и компьютере заказчика. Системные окна установки нельзя одинаково
автоматизировать для всех платформ.
